# Language starters

The [Rust](rust/README.md), [Python](python/README.md), and [TypeScript](typescript/README.md) starters run the same customer-review fixture. All three validate the prepared result, recompute unique review counts, and pass nine shared rejection cases without provider credentials.

The Rust web app also uses the Rust starter as a library. Python and TypeScript are local CLI examples. Start with the [shared template](../templates/customer-review-triage/README.md) to adapt categories, examples, and validation rules.

A second example and testing how developers adapt the starters are still open. See the [plan](../plan.md).
