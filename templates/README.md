# Task templates

[Customer-review triage](customer-review-triage/README.md) is implemented and shared by the Rust web app and all three language starters. It includes the task definition, synthetic reviews, a reference result, and rejection cases.

Give any new task its own folder with a task definition, representative synthetic input, expected output, and validation cases. See the [language starters](../starters/README.md) for examples that consume these files.
